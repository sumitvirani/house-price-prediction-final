# 🏠 House Price Prediction

A **production-ready** machine-learning web application that predicts California median house prices using a **GradientBoostingRegressor** trained on the [California Housing Dataset](https://scikit-learn.org/stable/datasets/real_world.html#california-housing-dataset).

| Layer | Technology |
|-------|-----------|
| ML Model | scikit-learn – GradientBoostingRegressor |
| Backend API | FastAPI + Uvicorn |
| Frontend | Streamlit + Plotly |
| Data | California Housing (sklearn built-in) |
| Deployment | Render (backend) + Streamlit Community Cloud (frontend) |

---

## ✨ Features

- **Real-time predictions** via FastAPI REST API
- **Interactive Streamlit dashboard** with 4 pages:
  - 🔮 Predict Price – enter features, get instant prediction + confidence range
  - 📊 Data Explorer – histograms, geographic map, correlation matrix
  - 🤖 Model Insights – performance metrics, feature importance chart
  - ℹ️ About – documentation and API reference
- **Production-grade** error handling, input validation, and CORS
- **Docker** support (backend + frontend containers)
- **Render** backend deployment ready
- **Streamlit Community Cloud** frontend deployment ready

## 🚀 Quick Start (Local Development)

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the Model

```bash
python model/train.py
```

This generates: `model/model.pkl`, `model/scaler.pkl`, `model/metrics.json`,
`model/feature_importance.csv`, `model/feature_info.json`, and `data/house_data.csv`.

### 3. Start the FastAPI Backend

```bash
uvicorn backend.main:app --reload --port 8000
```

Open <http://localhost:8000/docs> for interactive API docs.

### 4. Start the Streamlit Frontend

In a second terminal:

```bash
streamlit run streamlit_app.py
```

Open <http://localhost:8501> in your browser.

## 🔌 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | API root and links |
| GET | `/health` | Health check and model status |
| GET | `/feature-info` | Feature metadata (ranges, descriptions) |
| GET | `/metrics` | Model evaluation metrics |
| GET | `/model-info` | Model metadata |
| POST | `/predict` | Predict house price |

### POST /predict — Example

**Request:**
```json
{
  "MedInc":     3.87,
  "HouseAge":   28.0,
  "AveRooms":   5.43,
  "AveBedrms":  1.10,
  "Population": 1425.0,
  "AveOccup":   3.07,
  "Latitude":   35.63,
  "Longitude":  -119.57

```

**Response:**
```json
{
  "predicted_price":  198450.00,
  "price_range_low":  168682.50,
  "price_range_high": 228217.50,
  "currency":         "USD",
  "model_version":    "1.0.0",
  "input_features":   { ... }
}
```

## ☁️ Deployment

### Render (Backend)

See [`deployment/DEPLOY.md`](deployment/DEPLOY.md) for step-by-step instructions.

**Quick summary:**
1. Push this repo to GitHub.
2. Create a **Web Service** on [Render](https://render.com).
3. Set **Start Command**: `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`
4. Set **Build Command**: `pip install -r requirements.txt && python model/train.py`
5. Deploy. Render provides a public URL like `https://house-price-api-xxxx.onrender.com`.

### Streamlit Community Cloud (Frontend)

1. Push this repo to GitHub.
2. Go to [streamlit.io/cloud](https://streamlit.io/cloud) → **New app**.
3. Set **Main file path**: `streamlit_app.py`
4. Add **Secret**:
   ```
   API_BASE = https://your-render-url.onrender.com
   ```
5. Deploy.

## 🛠 Troubleshooting

| Problem | Solution |
|---------|----------|
| `model.pkl not found` | Run `python model/train.py` |
| `Cannot connect to backend` | Check `API_BASE` env variable; start backend |
| `422 Validation Error` | Verify input ranges match feature constraints |
| `503 Service Unavailable` | Model not loaded; check backend logs |
| Streamlit shows warning | Backend unreachable; start API server first |
| Docker build fails | Run `python model/train.py` before `docker-compose up` |
